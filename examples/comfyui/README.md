# SenseNova-U1.6 in ComfyUI

Open **Workflow → Browse Workflow Templates** in ComfyUI and search for
**SenseNova U1.6**. See the [official template guide](https://docs.comfy.org/interface/features/template).

- [SenseNova U1.6: Text to Image](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_sensenova_u16_t2i.json)
- [SenseNova U1.6: Image Edit](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_sensenova_u16_image_edit.json)

Both templates include prompt enhancement (`Enable PE`), an
8-step LoRA switch (`Turbo Mode?`), a self-correction path, and model download links.
