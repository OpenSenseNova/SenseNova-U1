# SenseNova-U1.5 Cookbook

<p align="center">
  <strong>English</strong> | <a href="./u1.5_best_practices_CN.md">简体中文</a>
</p>

This guide first introduces SenseNova-U1.5 inference, followed by the strongly recommended Image PE workflow for transforming text-to-image requests into a format closer to the model's training prompts. It also provides recipes for reference-image decomposition and complex editing.

## Quick Start

The reference inference implementation is available in the [SenseNova-U1 GitHub repository](https://github.com/OpenSenseNova/SenseNova-U1).

### Installation

```bash
git clone https://github.com/OpenSenseNova/SenseNova-U1.git
cd SenseNova-U1
uv sync
source .venv/bin/activate
```

The upstream environment currently uses Python 3.11, PyTorch 2.8, and CUDA 12.8. For other CUDA versions and optional FlashAttention configurations, see the [installation guide](./installation.md).

### Text-to-Image

```bash
python examples/t2i/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --prompt "A cinematic mountain lake at sunrise, realistic photography." \
  --width 2048 --height 2048 \
  --device_map auto \
  --output output.png
```

### Image Editing

```bash
python examples/editing/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --image input.png \
  --prompt "Change the jacket to cobalt blue. Preserve the face, pose, background, lighting, and framing." \
  --output edited.png
```

See [`examples/README.md`](../examples/README.md) for more inference options, supported resolutions, and batch processing.

## Recipes (Best Practices)

We recommend using Image PE as the default step before inference to help the model interpret subjects, composition, visible copy, spatial relationships, and canvas settings more consistently. Caption-to-Prompt and Editing PE are intended for reference-based creation and image editing, respectively.

### Recipe 1: Image Prompt Enhancement

Use the standalone [Image PE script](../src/sensenova_u1_5/image_pe.py) to convert a short brief into compact Render JSON while preserving required subjects, visible copy, counts, layout constraints, and exclusions. It is a Python entrypoint for any OpenAI-compatible Responses API:

```bash
pip install openai
export PE_MODEL_API_KEY="your-api-key"
export PE_MODEL_API_BASE_URL="https://your-provider.example/v1"

python src/sensenova_u1_5/image_pe.py \
  --prompt "Create a vertical independent book-fair poster. Exact copy: 'PAPER TRAIL', '7 NOV', 'CENTRAL LIBRARY'. Add no other text." > enhanced_prompt.json
```

Pass the resulting JSON directly to text-to-image inference:

```bash
python examples/t2i/inference.py \
  --model_path sensenova/SenseNova-U1.5-8B-MoT \
  --prompt "$(cat enhanced_prompt.json)" \
  --width 1664 --height 2496 \
  --device_map auto \
  --output output.png
```

We recommend `gpt-5.6-terra` for Prompt Enhancement. GPT models can optionally use hosted web search to ground current or source-dependent facts:

```bash
python src/sensenova_u1_5/image_pe.py \
  --prompt "Search the web to verify the west facade and reconstructed spire of Notre-Dame de Paris after its 2024 reopening. Create a portrait architecture-magazine cover titled 'NOTRE-DAME REBORN' with no other text." \
  --enable-gpt-search
```

### Recipe 2: Caption-to-Prompt

**Best for:** reconstructing or adapting the composition and visual language of a reference image.

When abstract style terms are insufficient, use the [Caption script](../src/sensenova_u1_5/caption/caption.py) to extract a reference image's visual decisions into an editable prompt:

```bash
pip install openai pillow
export OPENAI_API_KEY="your-api-key"

python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg
python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg > result.json
```

Use the generated prompt as a starting point: preserve the useful layout or visual language while replacing the theme, copy, subject, palette, or local structure. Only use reference images whose source, authorization, and license permit the intended use.

### Recipe 3: Editing Prompt Enhancement

**Best for:** complex edits, multiple input images, or requests with strict preservation requirements.

Editing PE rewrites the prompt; it does not modify pixels itself. State the requested change and everything that must remain unchanged. For multi-image tasks, provide images in their intended order and explain each image's role.

To inspect the rewritten prompt without running generation:

```bash
export OPENAI_API_KEY="your-api-key"

python src/sensenova_u1_5/edit/edit_pe.py \
  path/to/input.png \
  "Change the sky to a sunset while preserving the subject, pose, and framing."
```

Enable it in the editing inference entrypoint with `--use-edit-pe`. Use `--print-edit-pe` to compare the original and rewritten prompts, or `--edit-pe-model` to select the rewriter model.
