# SenseNova-U1.6

<p align="center"><a href="./u1.6_model.md">English</a> | <strong>简体中文</strong></p>

SenseNova-U1.6 在 U1.5 的基础上，将视觉理解和图像生成结合在同一个模型中。它着重改善人像、海报和插画的美感与创意表达，并为文字密集的信息图提供原生自修正能力。[U1.6 效果展示](u1.6_showcases_CN.md)收录了提示词、编辑案例，以及模型的修正意见和前后对照。

## U1.6 的主要变化

- **针对创作场景提供美学反馈。** U1.6 为不同类型的内容训练美学模型。人像和写实场景关注质感与光影，信息图则同时关注文字准确性、字体表现和版式，帮助保留艺术字、空间透视和画面构图。
- **原生自修正。** 生成首张信息图后，模型可以对照原始提示词检查画面，给出文字修正意见，并结合提示词和初始图像生成修改稿。生成、检查和修改在同一次生成中完成，可处理文字模糊、错字、乱码和编号错误等问题。自修正训练聚焦信息图，案例页也展示了部分其他类型图像上的效果。
- **扩展多专家、多奖励训练。** U1.6 在 U1.5 的后训练框架上，为不同内容类型和能力方向引入更多专家，每个专家使用多种奖励信号，再通过多专家在线策略蒸馏（MOPD）将各专家的能力汇集到同一个模型。

## 本地运行

请先按[安装指南](installation_CN.md)配置环境，再从仓库根目录运行以下命令，下载原版 BF16 权重及其配置和 tokenizer 文件。已有这份权重时，可将 `MODEL_PATH` 指向现有目录。

```bash
MODEL_PATH=./models/SenseNova-U1.6-8B-MoT
hf download sensenova/SenseNova-U1.6-8B-MoT \
  --revision 8f582699bac7f1e5362df2a776397d0e1a963b6c --local-dir "$MODEL_PATH"
```

### 文生图

```bash
python examples/t2i/inference.py --model_path "$MODEL_PATH" \
  --prompt "A two-tone jazz concert poster with the title MIDNIGHT JAZZ." \
  --output outputs/u1.6/text-to-image.png
```

### 图像编辑

先运行[图像编辑案例页](u1.6_showcases_CN.md#image-editing)的下载命令。下方 JSONL 会读取已下载的参考图。

```bash
python examples/editing/inference.py --model_path "$MODEL_PATH" \
  --jsonl examples/editing/data/sample_edit_u16_gallery.jsonl \
  --output_dir outputs/u1.6/editing
```

### 原生自修正

```bash
python examples/interleave/self_correction.py --model_path "$MODEL_PATH" \
  --prompt "Create a concert poster with the exact title MIDNIGHT JAZZ and the date May 12." \
  --output_dir outputs/u1.6/self-correction
```

通用参数见 [CLI 示例](../examples/README_CN.md)，权重放置和 Turbo 配置见 [ComfyUI 原生工作流](../examples/comfyui/README.md)。下载命令已通过只读取元数据的 dry run 核对固定版本，CLI 参数也已用 `--help` 核对。本指南未使用 U1.6 权重运行 GPU 推理。
