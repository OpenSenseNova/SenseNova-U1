## 最佳实践

> **能力归因说明：** Image PE、Caption-to-Prompt 和 Editing PE 均属于模型之外的可选规划工作流。所有使用 PE 的案例和评测结果都应明确标注。

### 如何选择

| 场景 | 推荐方式 |
| :--- | :------- |
| 主体明确、约束较少 | 直接使用自然语言 Prompt |
| 只有简短创意需求，但需要完整设计方案 | SenseNova Image PE Skill |
| 已找到理想构图或视觉语言，希望复现、换主题或修改 | 参考图检索 + Caption-to-Prompt |
| 复杂编辑、多张参考图或大量保留约束 | Editing PE |

### SenseNova Image PE Skill

使用 [Image PE Skill](../src/sensenova_u1_5/prompt-enhancement-skill/SKILL.md) 将简短需求转换为紧凑的 Render JSON，同时保留必需主体、可见文案、数量、版式约束和排除项。

在仓库根目录下，将 Skill 复制到 Agent skills 目录：

```bash
SKILL_DIR="$HOME/.agents/skills/sensenova-u1-5-prompt-enhancement"
mkdir -p "$SKILL_DIR"
cp src/sensenova_u1_5/prompt-enhancement-skill/SKILL.md "$SKILL_DIR/"
cp -R src/sensenova_u1_5/prompt-enhancement-skill/agents \
  src/sensenova_u1_5/prompt-enhancement-skill/references \
  "$SKILL_DIR/"
```

通过 Agent 的 Skill 机制调用 `sensenova-u1-5-prompt-enhancement`。建议使用以下请求形式：

```text
Convert the brief below into one compact Render JSON object. Preserve the
required visible copy, counts, layout constraints, and exclusions. Return only
the JSON object.

Brief: ...
```

仓库中的婚礼邀请函案例包含[简短需求输出](../src/sensenova_u1_5/prompt-enhancement-skill/examples/u1_5_pe_skill_wedding_raw.jpg)、[Render JSON](../src/sensenova_u1_5/prompt-enhancement-skill/examples/u1_5_pe_skill_wedding_prompt.json) 和 [PE 增强输出](../src/sensenova_u1_5/prompt-enhancement-skill/examples/u1_5_pe_skill_wedding_enhanced.jpg)。

### 参考图检索与 Caption-to-Prompt

当抽象风格词不足以表达目标时，选择设计完成度较高且授权合规的参考图，再使用 [Caption 脚本](../src/sensenova_u1_5/caption/caption.py) 将其视觉决策提取为可编辑 Prompt：

```bash
pip install openai pillow
export OPENAI_API_KEY="your-api-key"

python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg
python src/sensenova_u1_5/caption/caption.py path/to/reference.jpg > result.json
```

这条路径的目标是理解参考图为何有效，而非简单复制。在保留有价值的版式或视觉语言的同时，替换主题、文案、主体或局部结构。使用参考图时，必须遵守其来源、授权与许可协议。

### Editing PE

Editing PE 只负责重写 Prompt，不会自身修改像素。需同时说明要求的变更与必须保持不变的内容。多图任务中，请按预期顺序提供图像，并说明每张图像的作用。

如需在不执行生成的情况下查看重写后的 Prompt：

```bash
export OPENAI_API_KEY="your-api-key"

python src/sensenova_u1_5/edit/edit_pe.py \
  path/to/input.png \
  "将天空改为晚霞，保持主体、姿态和构图不变。"
```

在图像编辑推理入口中使用 `--use-edit-pe` 启用。使用 `--print-edit-pe` 可对比原始与重写后的 Prompt，使用 `--edit-pe-model` 可选择重写模型。

### 推理调节

- 从 `cfg_scale=4.0`、`timestep_shift=3.0` 和 `num_steps=50` 开始。
- 如果密集高频纹理或鲜艳色彩表现过强或过饱和，可逐步降低 `cfg_scale`。较低的 CFG 也可能减弱 Prompt 遵循，建议按具体 Prompt 对比结果。
- 图像编辑需同时写清目标修改与保留要求。为获得更可预期的行为，建议按原始长宽比将输入预缩放至约 2048×2048 分辨率。
- 在效果展示和评测中，需明确区分 PE 辅助结果与原始模型结果。
