# SenseNova-U1.6

<p align="center"><strong>English</strong> | <a href="./u1.6_model_CN.md">简体中文</a></p>

SenseNova-U1.6 builds on U1.5 and brings visual understanding and image generation together in one model. It focuses on visual quality and creative expression in portraits, posters, and illustrations, and on native self-correction for text-rich infographics. The [U1.6 showcases](u1.6_showcases.md) include prompts, edits, and before-and-after examples with the model's critiques.

## What changed in U1.6

- **Aesthetic feedback tailored to the image.** U1.6 uses aesthetic models trained for different kinds of content. For portraits and realistic scenes, the feedback emphasizes texture and lighting. For infographics, it covers lettering and layout as well as text accuracy, helping preserve decorative typography, perspective, and composition.
- **Native self-correction.** After generating an infographic, the model can compare it with the original prompt, write a critique, and generate a revision using the prompt and initial image. This lets it address problems such as blurred text, typos, garbled characters, and incorrect numbering in one generation process. Self-correction training focused on infographics. The showcase also illustrates the behavior on some other image types.
- **Expanded multi-expert, multi-reward training.** U1.6 extends U1.5's post-training with more experts for different content types and capabilities. Each expert uses multiple reward signals. Multi-expert on-policy distillation (MOPD) combines their capabilities in a single model.

## Workflows

| Workflow | Input | Output |
| --- | --- | --- |
| [Text-to-image](u1.6_showcases.md#text-to-image) | A text prompt | A new image |
| [Image editing](u1.6_showcases.md#image-editing) | A reference image and an edit instruction | An edited image |
| [Native self-correction](u1.6_showcases.md#self-correction) | A text prompt, optionally with a reference image | An image revision guided by the model's critique |

## Run locally

Follow the [shared installation guide](installation.md) and run the commands from the repository root. Download the original BF16 checkpoint with its configuration and tokenizer files, or set `MODEL_PATH` to an existing copy of that checkpoint.

```bash
MODEL_PATH=./models/SenseNova-U1.6-8B-MoT
hf download sensenova/SenseNova-U1.6-8B-MoT \
  --revision 8f582699bac7f1e5362df2a776397d0e1a963b6c --local-dir "$MODEL_PATH"
```

### Text-to-image

```bash
python examples/t2i/inference.py --model_path "$MODEL_PATH" \
  --prompt "A two-tone jazz concert poster with the title MIDNIGHT JAZZ." \
  --output outputs/u1.6/text-to-image.png
```

### Image editing

First run the input download command in the [editing showcase](u1.6_showcases.md#image-editing). The JSONL then reads the downloaded reference images.

```bash
python examples/editing/inference.py --model_path "$MODEL_PATH" \
  --jsonl examples/editing/data/sample_edit_u16_gallery.jsonl \
  --output_dir outputs/u1.6/editing
```

### Native self-correction

```bash
python examples/interleave/self_correction.py --model_path "$MODEL_PATH" \
  --prompt "Create a concert poster with the exact title MIDNIGHT JAZZ and the date May 12." \
  --output_dir outputs/u1.6/self-correction
```

See the [CLI examples](../examples/README.md) for shared options and the [native ComfyUI workflows](../examples/comfyui/README.md) for checkpoint placement and Turbo setup. The pinned checkpoint was checked with a metadata-only download dry run, and the CLI options were checked with `--help`. GPU inference with a U1.6 checkpoint was not run for this guide.
